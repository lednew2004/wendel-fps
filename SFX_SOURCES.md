# Titan Protocol — Origem dos efeitos sonoros

Os sons de tiro / recarga podem ser baixados automaticamente pelo script `scripts/install-sfx.mjs`. Fontes listadas aqui têm licença CC0 publicada pelos autores.

1. OpenGameArt, **kurt**, *Gunshots* (pistola, magnum e pólvora negra). Licença CC0: https://opengameart.org/content/gunshots
2. OpenGameArt, **SpringySpringo**, *Gun reload sounds* (recarga de rifle e ação de espingarda). Licença CC0: https://opengameart.org/content/gun-reload-sounds

O instalador obtém os WAV pelos links diretos publicados nas páginas dos autores, recorta o impacto mais forte para uso como SFX curto quando o formato é compatível e salva os arquivos locais em `public/assets/sfx`. Downloads falhados não interrompem a instalação e **não apagam** os arquivos de reserva. É necessário acesso à internet para a substituição por gravações reais.

Os demais sons locais de reserva foram sintetizados especialmente para esta compilação (sem uso de material de terceiros); não são gravações de armas reais.
